# Development-company-Enterprise
A professional AI development workspace that connects to top coding models via official runtimes, supports custom .md agents, and automates full project workflows from brief to deployment with real-time execution, previews, and client-ready delivery packages.
Double-click Hayek_Enterprise.exe.

Agents folder:
Put any custom .md agent inside the agents folder, then open the app and click Agent company > Scan agents. The app will copy your agents into every generated project and include them in the company board and master prompt.

AI authorization:
Use Authorize selected AI to launch the selected provider's official coding-runtime login. For OpenAI, install Codex then authorize; Codex opens the ChatGPT sign-in flow and stores credentials locally through the official runtime. For web-only chat, use Open web chat; the prompt is copied for manual use in the browser.

IMPORTANT the user must install the selected runtime first, for example Codex CLI for OpenAI. Then Authorize selected AI opens the real login flow and the app can launch that runtime for the agents.
